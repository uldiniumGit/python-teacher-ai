# Variables

## Definition

В Python переменная — это имя, связанное с объектом в определённом пространстве имён.

Оператор присваивания используется для связывания имени с объектом:

```python
age = 25
name = "Roman"
```

После выполнения `age = 25` имя `age` ссылается на объект, представляющий целое число `25`.

В Python переменная не имеет фиксированного типа, который был бы задан при её создании. Тип относится к объекту, а имя может быть повторно связано с объектом другого типа:

```python
value = 10
value = "Python"
```

После второго присваивания имя `value` связано со строковым объектом.

Присваивание не копирует объект. Оно связывает имя с существующим объектом:

```python
numbers = [1, 2, 3]
other = numbers
```

Теперь оба имени связаны с одним объектом списка.

---

## Purpose

Переменные используются для:

* хранения ссылок на данные;
* повторного использования значений в программе;
* передачи данных между операциями и функциями;
* создания понятных имён для объектов;
* изменения того, с каким объектом связано определённое имя.

Например:

```python
price = 100
quantity = 3

total = price * quantity
```

Вместо повторного использования числовых литералов программа работает с именами, которые описывают смысл данных.

Переменные особенно важны при работе с изменяемыми данными, функциями, циклами, условиями, классами и другими конструкциями Python.

## Core Concepts

### Names and Objects

В Python имя и объект — разные понятия.

Объект содержит данные и имеет тип. Имя является способом обратиться к объекту через пространство имён.

Например:

```python
x = 10
```

Здесь `10` — объект типа `int`, а `x` — имя, связанное с этим объектом.

Несколько имён могут ссылаться на один объект:

```python
x = [1, 2, 3]
y = x
```

В этом случае `x` и `y` связаны с одним списком.

---

### Assignment

Оператор `=` связывает имя с результатом вычисления выражения:

```python
x = 10
```

Сначала вычисляется выражение справа от `=`, затем результат связывается с целью присваивания слева.

Имя может быть связано с новым объектом повторно:

```python
x = 10
x = 20
```

После второго присваивания `x` связано с объектом `20`.

Если имя уже существовало, оно становится связанным с новым объектом.

---

### Multiple Assignment

Python позволяет выполнять несколько присваиваний в одном операторе:

```python
x, y = 10, 20
```

В этом случае значения распределяются между соответствующими целями.

Можно также присвоить одно значение нескольким именам:

```python
x = y = 0
```

После этого оба имени связаны с одним объектом `0`.

---

### Unpacking

При распаковке элементы итерируемого объекта присваиваются нескольким целям:

```python
numbers = [10, 20, 30]

x, y, z = numbers
```

Теперь:

```python
x == 10
y == 20
z == 30
```

Количество элементов должно соответствовать количеству целей, если не используется starred target.

Можно использовать `*` для получения списка оставшихся элементов:

```python
numbers = [1, 2, 3, 4, 5]

first, *middle, last = numbers
```

Результат:

```python
first == 1
middle == [2, 3, 4]
last == 5
```

Starred target получает список оставшихся элементов и может оказаться пустым.

---

### Swapping Variables

Благодаря multiple assignment значения двух переменных можно поменять местами без отдельной временной переменной:

```python
a = 10
b = 20

a, b = b, a
```

После выполнения:

```python
a == 20
b == 10
```

Это является следствием правил множественного присваивания и распаковки.

---

### Dynamic Typing

Python использует динамическую типизацию.

Имя не закрепляется за определённым типом:

```python
value = 10
value = "hello"
value = [1, 2, 3]
```

Один и тот же идентификатор может последовательно быть связан с объектами разных типов.

При этом сами объекты имеют определённый тип:

```python
value = 10
type(value)  # int

value = "hello"
type(value)  # str
```

---

### Mutability and References

Присваивание имени изменяемому объекту не создаёт независимую копию объекта.

Например:

```python
numbers = [1, 2, 3]
other = numbers

other.append(4)
```

Теперь:

```python
numbers
# [1, 2, 3, 4]

other
# [1, 2, 3, 4]
```

Оба имени относятся к одному списку.

Это особенно важно при работе со списками, словарями, множествами и другими изменяемыми объектами.

---

### Variable Annotations

Python поддерживает аннотации переменных:

```python
age: int = 25
name: str = "Roman"
```

Аннотация описывает предполагаемый тип значения, но сама по себе не заставляет Python проверять соответствие значения указанному типу во время выполнения:

```python
age: int = "hello"
```

Такая запись синтаксически допустима, хотя значение не соответствует указанной аннотации.

Аннотации используются, в частности, статическими анализаторами, IDE и инструментами типизации.

Python 3.14 изменил семантику вычисления аннотаций: аннотации в соответствующих случаях вычисляются лениво в отдельной annotation scope.

---

### Scope

Имя существует в определённом пространстве имён.

В зависимости от места определения и правил разрешения имён Python может работать с локальными, глобальными и нелокальными именами.

Например:

```python
x = 10

def function():
    x = 20
    print(x)

function()
print(x)
```

Результат:

```text
20
10
```

`x` внутри функции — локальное имя, а `x` вне функции — глобальное имя.

Для явного изменения глобального имени внутри функции используется `global`:

```python
counter = 0

def increment():
    global counter
    counter += 1
```

Для обращения к имени из окружающей функции используется `nonlocal`.

Подробные правила областей видимости рассматриваются отдельно в теме функций и namespaces/scopes.

---

### Naming Rules

Имя переменной должно быть допустимым идентификатором Python.

Идентификатор может содержать:

* буквы;
* цифры;
* символ `_`.

Имя не может начинаться с цифры.

Допустимые имена:

```python
name = "Roman"
age2 = 27
user_name = "Roman"
_private = 10
```

Недопустимое имя:

```python
2users = 10
```

Ключевые слова Python нельзя использовать как обычные идентификаторы:

```python
class = 10
```

Это приведёт к `SyntaxError`.

Имена чувствительны к регистру:

```python
name = "Roman"
Name = "John"
```

`name` и `Name` — разные имена.

## Syntax

Базовое присваивание:

```python
name = expression
```

Примеры:

```python
age = 27
name = "Roman"
result = 10 + 20
```

Несколько присваиваний:

```python
x, y = 10, 20
```

Цепочное присваивание:

```python
x = y = 0
```

Распаковка:

```python
x, y, z = [10, 20, 30]
```

Распаковка со starred target:

```python
first, *middle, last = [1, 2, 3, 4, 5]
```

Аннотированное присваивание:

```python
age: int = 27
name: str = "Roman"
```

Составное присваивание:

```python
x += 1
x -= 1
x *= 2
x /= 2
```

Полный синтаксис assignment statements и правила целей присваивания определены в Language Reference.

## Rules

### Assignment binds names to objects

Присваивание связывает имя с объектом, а не копирует значение объекта:

```python
x = [1, 2, 3]
y = x
```

`x` и `y` связаны с одним объектом списка.

---

### Right-hand side is evaluated before assignment

При обычном присваивании выражение справа вычисляется перед связыванием результата с целью:

```python
x = 10 + 20
```

Сначала вычисляется `10 + 20`, затем результат `30` связывается с `x`.

---

### Multiple assignment requires compatible unpacking

При:

```python
a, b = [1, 2]
```

количество элементов соответствует количеству целей.

Если количество элементов не совпадает и не используется starred target, возникает ошибка:

```python
a, b = [1, 2, 3]
```

Результат:

```text
ValueError
```

---

### Starred target receives a list

При распаковке starred target получает список оставшихся элементов:

```python
first, *rest = [1, 2, 3, 4]
```

Результат:

```python
first == 1
rest == [2, 3, 4]
```

Даже если элементов не осталось, значение starred target будет пустым списком:

```python
first, *rest = [1]
```

Результат:

```python
rest == []
```

---

### Assignment can target attributes and items

Присваивание применяется не только к именам:

```python
user.name = "Roman"
```

или к элементам изменяемых объектов:

```python
numbers = [1, 2, 3]
numbers[0] = 100
```

Для таких операций поведение определяется соответствующим объектом.

Для подписанного объекта Python использует механизм `__setitem__()`.

---

### Augmented assignment

Составное присваивание объединяет операцию и присваивание:

```python
x += 1
```

Оно похоже на:

```python
x = x + 1
```

но эти операции не во всех случаях полностью эквивалентны.

Составное присваивание вычисляет левую часть только один раз и может выполнять операцию непосредственно над существующим объектом, если тип объекта поддерживает такое поведение.

Например, для изменяемых объектов это может приводить к изменению существующего объекта.

## Examples

### Example 1 — Basic assignment

```python
name = "Python"
version = 3.14

print(name)
print(version)
```

Имена `name` и `version` связываются с соответствующими объектами.

---

### Example 2 — Rebinding a name

```python
value = 10

print(value)

value = 20

print(value)
```

После второго присваивания имя `value` связано с объектом `20`.

---

### Example 3 — Different object types

```python
value = 100
print(type(value))

value = "Python"
print(type(value))

value = [1, 2, 3]
print(type(value))
```

Одно имя последовательно связывается с объектами разных типов.

---

### Example 4 — Multiple assignment

```python
name, age = "Roman", 27

print(name)
print(age)
```

Результат:

```text
Roman
27
```

---

### Example 5 — Swapping

```python
a = 10
b = 20

a, b = b, a

print(a)
print(b)
```

Результат:

```text
20
10
```

---

### Example 6 — Unpacking

```python
numbers = [10, 20, 30]

x, y, z = numbers

print(x)
print(y)
print(z)
```

Каждое значение присваивается соответствующей цели.

---

### Example 7 — Starred unpacking

```python
numbers = [1, 2, 3, 4, 5]

first, *middle, last = numbers

print(first)
print(middle)
print(last)
```

Результат:

```text
1
[2, 3, 4]
5
```

---

### Example 8 — Shared mutable object

```python
numbers = [1, 2, 3]
other = numbers

other.append(4)

print(numbers)
print(other)
```

Результат:

```text
[1, 2, 3, 4]
[1, 2, 3, 4]
```

Оба имени относятся к одному списку.

---

### Example 9 — Variable annotation

```python
name: str = "Python"
version: float = 3.14
```

Аннотации документируют предполагаемые типы переменных и могут использоваться инструментами статического анализа.

---

### Example 10 — Attribute assignment

```python
class User:
    pass

user = User()
user.name = "Roman"

print(user.name)
```

Здесь `user.name` является целью присваивания атрибута.

## Edge Cases

### Same object, different names

Следует отличать два имени, связанные с одним объектом, от двух независимых объектов:

```python
a = [1, 2]
b = a
```

Изменение через `b` изменяет объект, доступный через `a`:

```python
b.append(3)

print(a)
# [1, 2, 3]
```

---

### Immutable objects

Для неизменяемых объектов операция, которая выглядит как изменение значения, обычно приводит к связыванию имени с другим объектом:

```python
x = 10
x += 1
```

После операции `x` связан с результатом `11`.

Это отличается от поведения некоторых изменяемых объектов при составном присваивании.

---

### Assignment inside a function

Присваивание имени внутри функции обычно делает это имя локальным для функции:

```python
x = 10

def function():
    x = 20
    print(x)

function()
print(x)
```

Результат:

```text
20
10
```

---

### Unpacking with too many or too few values

Без starred target количество элементов должно соответствовать количеству целей:

```python
a, b = [1, 2, 3]
```

приведёт к `ValueError`.

То же относится к недостаточному количеству значений:

```python
a, b, c = [1, 2]
```

---

### Assignment does not create a copy

Следующий код не создаёт копию списка:

```python
a = [1, 2, 3]
b = a
```

Для создания отдельного объекта необходимо явно использовать соответствующий механизм копирования.

## Common Mistakes

### Mistake 1 — Confusing assignment with comparison

Неправильно:

```python
if x = 10:
    print("10")
```

`=` используется для присваивания.

Для сравнения используется `==`:

```python
if x == 10:
    print("10")
```

---

### Mistake 2 — Assuming assignment copies an object

Неправильно предполагать, что:

```python
a = [1, 2, 3]
b = a
```

создаёт два независимых списка.

На самом деле оба имени связаны с одним объектом.

---

### Mistake 3 — Wrong number of values during unpacking

Неправильно:

```python
a, b = [1, 2, 3]
```

Количество элементов не соответствует количеству целей.

Если необходимо получить оставшиеся элементы:

```python
a, *rest = [1, 2, 3]
```

---

### Mistake 4 — Assuming variable annotations enforce types

Аннотация:

```python
age: int = "twenty"
```

не является автоматической runtime-проверкой типа.

Аннотации предназначены прежде всего для информации о типах и инструментов статического анализа.

---

### Mistake 5 — Unexpected shared mutable object

Нужно помнить, что:

```python
a = []
b = a
```

создаёт два имени для одного списка.

Если изменить список через `b`, изменение будет видно через `a`.

---

### Mistake 6 — Confusing local and global names

Например:

```python
count = 0

def increment():
    count += 1
```

Такой код вызывает ошибку, поскольку `count` рассматривается внутри функции как локальное имя, но до присваивания локальное значение не было определено.

Если действительно требуется изменить глобальное имя, необходимо явно использовать `global`:

```python
count = 0

def increment():
    global count
    count += 1
```

Однако изменение глобального состояния следует применять осознанно.

## Key Takeaways

* В Python имя связано с объектом; переменная не является контейнером с фиксированным типом.
* Оператор `=` используется для присваивания и связывания имени с объектом.
* Одно имя может последовательно ссылаться на объекты разных типов.
* Несколько имён могут ссылаться на один объект.
* Присваивание объекта переменной не создаёт его копию.
* Python поддерживает multiple assignment и unpacking.
* Starred target (`*name`) получает список оставшихся элементов при распаковке.
* Имена чувствительны к регистру.
* Идентификаторы должны соответствовать правилам Python и не могут совпадать с ключевыми словами.
* Область видимости определяет, какое имя используется в конкретном контексте.
* Аннотации переменных описывают ожидаемые типы, но сами по себе не выполняют обычную runtime-проверку типов.
* Составное присваивание (`+=`, `-=`, `*=` и т. д.) имеет собственную семантику и в некоторых случаях может изменять существующий объект на месте.
